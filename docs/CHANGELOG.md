# История изменений

## Unreleased

- Исправлена привязка диагностики к исходному профилю и модели при переключениях во время запроса. Сбои консоли не влияют на результат; код ошибки и идентификаторы поиска сохраняются.

- DevTools Console показывает JSON-диагностику поиска и ошибок чата: статусы планировщика/embeddings, режимы Thinking, доступные причины остановки и лимиты; тексты запросов, ответов и источников исключены.

- Планировщик поиска явно отключает native thinking при запросе JSON: Qwen3 больше не расходует бюджет плана на внутреннее размышление. Ошибки незавершённого плана, схемы и тайм-аута различаются без вывода личных данных.

- В настройках системы добавлен сохраняемый интервал предупреждения о долгом поиске в секундах; отмена остаётся явной.

- Thinking показывает все режимы в одном сегментном ряду: Auto / On / Off либо Auto и объявленные моделью именованные уровни.
- У пользовательских плашек отключено backdrop-размытие внутри маски прокрутки для предотвращения возможных артефактов композитинга; градиенты, тени и оформление ответов сохранены.

- Добавлена настройка семантического поиска через «Знания»: предложение установки при первом запуске, загрузка embedding-модели с прогрессом/отменой, проверка совместимости и отдельное включение индекса выбранного профиля без .env и перезапуска. Старый provider переключается только после успешной переиндексации; настройки других профилей сохраняются.

- Исправлена прокрутка при стриминге: ручное движение вверх отключает следование даже возле низа; новые фрагменты, завершение и отмена запроса сохраняют позицию чтения. Явный возврат к последнему сообщению возобновляет следование.

- После отправки запроса появляются три точки ожидания до первого текста или доступного reasoning; временный индикатор не сохраняется в историю и не меняет прокрутку.
- У поиска убран общий 90-секундный обрыв. Фоновая задача продолжает работать во время подтверждения ожидания через 30 секунд; отмена возвращает запрос в input и предотвращает позднюю запись результата. Индекс и токены повторно используются в пределах одного запроса.

- Подсказка поиска открывается только через «?», а не при наведении на строку или фокусе переключателя. Видимый знак уменьшен до круглых 24px; сохранена удобная область нажатия.

- Завершён умный поиск: локальный LLM-планировщик, отдельные запросы по темам/вариантам, объединение лексического и локального семантического поиска при настроенной embedding-модели, исходные цитаты. Hash-режим явно обозначается как поиск без семантики; живой индекс автоматически не мигрирует.
- Ссылки добавляются только по запросу: подтверждённый источник permalink Telegram либо безопасная локальная копия индексированного фрагмента. Ссылки кликабельны, содержимое цитат остаётся инертным.
- Переключатель поиска перенесён в меню RAG; вместо большой кнопки над полем показывается маленький индикатор справа от микрофона только в активном режиме. Вёрстка GPT-6 Luna High, логика и проверки интегрированы отдельно.

- Добавлен режим «Поиск в базе»: локальный поиск без генерации LLM, исходные фрагменты с источниками и Telegram ID/датами, сохранение результата в чате, отмена и защита от запоздалых ответов.
- Неверные assistant-обёртки исключаются из истории и summary snapshots. Проверка выполняется до continuation; разрешена одна попытка восстановления с сокращённой историей и сохранённой защитой, только пока текст/reasoning не выданы клиенту.

- Во время генерации чат сохраняет позицию чтения: убраны повторные smooth-scroll и принудительный переход вниз при обновлении текущей сессии. Автопрокрутка следует за концом ответа, пока пользователь находится внизу.
- Интерфейс скрывает DATA_ENVELOPE в старых assistant-ответах за понятной ошибкой с повтором запроса, без изменения сохранённой истории. Проверены 72 frontend-теста, 38 backend-тестов защиты и синтетическая генерация в Chrome.

- Копирование пользовательского сообщения и ответа модели показывает «Скопировано / Сообщение скопировано» после каждого успешного копирования: для этой операции отключено подавление повторных тостов на 8 секунд. Ошибка clipboard показывает уведомление об ошибке.

- Явный поиск Telegram-сообщений выдаёт карточки исходных RAG-фрагментов с датами, ID и источниками без модельного пересказа; результат обозначен как ограниченная выборка кандидатов. Темы через запятую разделяются при retrieval.
- История больше не задаёт assistant-пример служебной обёртки. DATA_ENVELOPE в генерации блокируется до выдачи клиенту, включая streaming. Проверено 479 Python-тестами на синтетических данных.

- В списке моделей убраны дублирующие Thinking-переключатели. Кнопка Thinking показывает выбранный режим на desktop/mobile; Auto визуально отделён от включённого состояния. Проверено 68 frontend-тестами.

- Thinking controls распознают native Ollama capabilities/template для Qwen3 4B/8B, сохраняя явные named levels других моделей. Добавлен адаптивный сегментный переключатель с отдельным Auto.
- История чата загружается независимо от вспомогательных сервисов и защищена от устаревших ответов; запрос виден во время подготовки контекста, composer восстанавливается при отказе отправки.

- RAG загружает большие выборки файлов пакетами: общий прогресс, накопление результатов, продолжение после per-file ошибок и сохранение предыдущих результатов при сетевом сбое. Проверена синтетическая выборка 34 HTML/69 MiB без доступа к личным файлам.

- При отказе загрузки RAG показывает причину и диагностический код в окне документов и DevTools Console, в том числе при HTTP 200 с per-file errors; содержимое файла в Console не выводится.

- Проверены большие Telegram-выгрузки: потоковая загрузка/разбор без фиксированного HTML byte limit; индекс chunk/model ускоряет поиск на больших корпусах. Исправлены временные границы, нормализация хэштегов, поиск ID по источникам и дословное извлечение исходного сообщения без LLM-перефразирования.

- RAG принимает HTML-выгрузки Telegram: отдельные сообщения с датой, автором и ID, local_hash, фильтрация дат и уточнения в обычном чате. Добавлена защита Telegram-данных от внешнего chat/embedding provider.

- Очищена Git-история перед публикацией исходного кода с сохранением хронологии разработки.
- Ограничена передача `HF_TOKEN` официальным HTTPS-запросом Hugging Face; авторизация снимается при небезопасном redirect.
- Проверяются пути имён загружаемых ASR-файлов и файлов Piper перед записью или удалением.
- faster-whisper загружает только явно подготовленные локальные модели; неявное скачивание из Hub при inference отключено.
- Python quality workflow выполняет полный scan на initial push и запуске для default branch.
