# 🧠 Память и контекст (текущее поведение)

Цель файла — зафиксировать, как сейчас работает память/контекст модели, чтобы понимать точку отсчёта и придумать, как удерживать более длинные диалоги по транскрибациям.

## Где реализовано
- Основная логика: `app/server.py`, эндпоинт `/chat`.
- Настройка объёма памяти: env `MEM_TURNS` (по умолчанию 6 пар user/assistant).

## Что попадает в prompt модели (/chat)
1. `system` — текст из `_system_prompt()`.
2. `context` — если передан в запросе, добавляется отдельным `user` сообщением.
3. `transcript` — из запроса; если пусто, подтягивается из памяти сессии (`SESSION_TRANSCRIPTS`).
4. `criteria` — из запроса; если пусто, берутся из памяти сессии (`SESSION_CRITERIA`).
5. История диалога — последние `MEM_TURNS` пар `user/assistant` из `SESSIONS[sid]`.
6. Текущий `user` запрос.

## Как хранится память
- Сессионный ключ: `session_id` из клиента (по умолчанию `"default"`).
- После ответа список истории обрезается до `2 * MEM_TURNS` элементов (только пары user/assistant).
- Транскрипт и критерии кешируются отдельно на сессию и переиспользуются, если в запросе пусто.
- Нет автоматического тримминга текста транскрипта или критериев.

## Ограничения/риски
- Фиксированный `MEM_TURNS`: старые ходы быстро выпадают, если диалог длиннее 6 обменов.
- Нет оценки токенов контекста: длинный транскрипт + история могут выбить модель из лимита.
- История хранится «как есть» без сжатия/резюме; критерии и транскрипт не переименовываются/не рефайнится.

## Идеи для увеличения удержания контекста
- Делать свёртку (summarize) старых ходов в компактное резюме по достижении порога токенов.
- Для транскриптов — хранить оригинал и короткий конспект; подмешивать конспект, а не полный текст, если контекст близок к лимиту.
- Учитывать таймлайн: передавать только релевантные фрагменты по последнему запросу (фильтр по времени/говорящему).
- Динамически регулировать `MEM_TURNS` с учётом `NUM_CTX`/`MAX_TOKENS` выбранной модели.
- Добавить предварительный расчёт токенов перед отправкой и при необходимости автоматически сокращать контекст (старые ходы, длинные критерии).
