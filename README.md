# 🧠 LocalGPT — локальный HR‑ и ASR‑бот

LocalGPT — полностью офлайн ассистент для разбора собеседований и стенограмм. Он работает на FastAPI + Ollama, не отправляет данные в интернет и хранит всё локально в каталоге проекта.

## Что такое LocalGPT и зачем он нужен
- Анализирует диалоги и транскрипты (Whisper/faster-whisper) без облаков.
- Отвечает через локальные LLM (Ollama) и поддерживает длинные контексты.
- Хранит профили, сессии, сообщения, транскрипты и настройки моделей в SQLite (`app/db/localgpt.db`), чтобы диалоги переживали перезапуски.
- Управляется через простой веб-интерфейс (`http://127.0.0.1:8000/ui/gui_html.html`) с подсказками и компактным справочником.

## Как установить и запустить
1) Установите зависимости: Python 3.10+, Ollama (с моделями Qwen/Llama/Mistral), ffmpeg.
2) Склонируйте репозиторий и запустите:
```
python3 run_localgpt.py
```
Скрипт сам создаст venv, подтянет зависимости из `app/requirements.txt`, проверит Ollama и откроет UI.  
3) Альтернатива вручную:
```
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r app/requirements.txt
ollama serve &
uvicorn app.server:app --host 127.0.0.1 --port 8000
```
4) Откройте браузер: `http://127.0.0.1:8000/ui/gui_html.html`.

## Как работать с профилями и сессиями
- В левом верхнем углу выберите профиль или создайте новый. Каждый профиль хранит свои диалоги, транскрипты и настройки моделей.
- В левой колонке — список сессий выбранного профиля. Кнопка «+ Новый диалог» создаёт сессию с выбранной моделью Ollama.
- Переключение между сессиями меняет `session_id` в запросах `/chat` и подтягивает историю сообщений из БД (последние `MEM_TURNS` пар user/assistant).
- Удаление профиля каскадно удаляет его сессии, сообщения, транскрипты и настройки.

## Как использовать транскрипции и настройки модели
- Транскрипции: загрузите аудио/видео или вставьте текст. Результат автоматически сохраняется в БД (таблица `transcripts`) и привязывается к профилю и, при наличии, к активной сессии. История транскриптов открывается в отдельном окне: можно переименовывать, удалять, подставлять в анализ или запускать «Анализ» сразу из списка.
- Настройки модели: в окне «Настройки» есть блок «Настройки модели (по профилю)». Для выбранных профиля и модели задайте `temperature`, `max_tokens`, `num_ctx`, `mem_turns`. «Сохранить» создаёт/обновляет запись в `model_settings`, «По умолчанию» сбрасывает к значениям из `.env`. В ответах `/chat` возвращаются `used_settings`.
- Критерии: загружайте CSV/XLSX или Google Sheets, они закрепляются за активной сессией (через `/criteria/parse`) и подмешиваются в промпт.

## Структура проекта
```
LocalGPT/
├── app/                # FastAPI backend, db.py, server.py, prompts/
├── web_ui/             # Веб-интерфейс (HTML, CSS, JS)
├── app/db/localgpt.db  # SQLite с профилями, сессиями, сообщениями и транскриптами
├── ollama_models/      # Каталог моделей Ollama (активный путь: ollama_models/models)
├── run_localgpt.py     # Упрощённый запуск
└── .env                # Настройки по умолчанию
```

> Примечание: при запуске backend выставляет `OLLAMA_MODELS` и `OLLAMA_MODELS_DIR` на `./ollama_models/models`. Каталог `ollama (delete)` — старый/неиспользуемый, его можно удалить после проверки содержимого.

## Примеры `.env`
Ключевые переменные:
```
LOCAL_MODEL=qwen2.5:3b
LOCAL_BASE_URL=http://127.0.0.1:11434/v1
LOCAL_API_KEY=LOCAL-KEY
TEMP=0.25
MAX_TOKENS=512
NUM_CTX=32768
MEM_TURNS=6
WHISPER_MODEL_SIZE=medium
```
Для длинного контекста поменяйте `LOCAL_MODEL`, `NUM_CTX`, `MAX_TOKENS`, `MEM_TURNS`. Если Ollama или API запущены на другой машине, задайте `LOCAL_BASE_URL` и `LOCAL_API_KEY`.

## Кастомизация системного промпта
Базовый HR-промпт хранится в `app/prompts/system_hr.md`. Отредактируйте его под свой тон и формат ответов. Если файл недоступен или повреждён, backend использует резервный встроенный промпт, чтобы сервис продолжал отвечать.

## Частые вопросы и решения
- **Модель не скачивается.** В настройках UI выберите модель из рекомендаций и нажмите «Скачать и выбрать». Бэкенд вызывает `ollama pull`, прогресс виден в блоке загрузок.
- **Whisper-модель не найдена.** Установите нужный вес в `ollama_models/whisper` или скачайте через интерфейс, затем перезапустите транскрипцию.
- **Диалоги/транскрипты пропали.** Проверьте, что приложение запущено из того же каталога и файл `app/db/localgpt.db` доступен на запись.
- **Слишком длинный запрос.** Смотрите строки «Лимит контекста» в UI: значения берутся из эффективных настроек модели. Сократите вход или уменьшите `max_tokens`.
- **Нужен новый профиль/песочница.** Создайте профиль в шапке UI — данные будут храниться отдельно и не затрутся при очистке браузера.

LocalGPT полностью офлайн: никакие данные не покидают вашу машину. Если что-то пошло не так — проверьте логи `run_localgpt.py` и `ollama.log`.
