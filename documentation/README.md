# LocalGPT Documentation Index

This folder is a centralized documentation hub for LocalGPT. It collects copies of the main project Markdown files so the project can be reviewed from one place.

Most files here are copies of source documents that still live in their original locations. Each copied file starts with a `Source:` note; update the source document first, then refresh the hub copy.
