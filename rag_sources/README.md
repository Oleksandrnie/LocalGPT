# LocalGPT RAG sources

Эта папка хранит локальные документы для RAG. Файлы внутри профильных папок являются runtime-данными и не должны попадать в git.

RAG-индексация не загружает LLM-модели. Документы можно добавлять и индексировать без локальной chat-модели, но ответы в чате с RAG-контекстом требуют выбранную установленную Ollama-модель.

## Как устроены папки

- Каждый профиль получает свою папку: `profile_<id>_<name>`.
- При смене профиля используется только RAG-папка активного профиля.
- Новый профиль начинает с пустой RAG-папки.
- При удалении профиля его RAG-папка удаляется.
- Мягкая очистка БД не удаляет ручные RAG-файлы и `manual_file` индекс.
- Полная очистка БД удаляет профильные RAG-папки и пересоздаёт пустой `Default` профиль.

## Как добавлять файлы

Открой UI -> `RAG` -> `Добавить файлы` -> выбери `.md` -> `Индексировать`.

После изменения файлов нужно снова нажать `Индексировать`. Эта кнопка пересобирает embeddings для Markdown-файлов.

Чтобы удалить файл, нажми `×` рядом с ним в списке RAG. Удаляется выбранный Markdown-файл и его запись в индексе.

## Один Markdown-файл на документ

Для каждого знания используйте один `.md`. В нём может быть и описание, и точные факты: заголовки, списки и таблицы Markdown хорошо подходят для тарифов, SLA, правил, шаблонов и договорённостей. Не создавайте JSON-дубль: он не будет добавлен в индекс.

Старые JSON-файлы остаются в папке, чтобы их можно было вручную перенести или сохранить как архив, но LocalGPT их не читает. После переноса нужных данных в Markdown нажмите `Индексировать` — старые JSON-записи будут удалены из SQLite-индекса, без удаления файлов с диска.

## Рекомендации для цен и расчётов

Для тарифов, ставок и расчётов записывайте числа в Markdown однозначно:

```text
7 часов — 23 730 ₽
```

Не используй запятую как разделитель тысяч в русских ценах:

- неправильно: `35,690 ₽`;
- правильно: `35 690 ₽`.

### Единый формат валют

- Российские рубли: символ после числа через обычный пробел — `119 600 ₽`, `2 990 ₽/час`.
- Доллары США: символ перед числом без пробела — `$500`, `$1,250`.
- Евро: символ перед числом без пробела — `€300`, `€1,250`.
- Не используйте слова и сокращения валюты вместо символа (`руб.`, `долл.`, `евро`) в тарифах, расчётах и коммерческих предложениях.
- Не используйте случайные или повреждённые символы валюты. Если валюта неизвестна, уточните её, а не подставляйте символ.

Во всех примерах, шаблонах и итогах одного коммерческого предложения используйте один и тот же формат. Например: `3 × 119 600 ₽ = 358 800 ₽`; после скидки: `950 670 ₽`.

Если в RAG-документе есть шаблон с расчётами, полезно явно указать правило:

```text
Расчёты показывать обычным текстом, без LaTeX/MathML/markdown-формул.
```

Chat runtime тоже добавляет это правило в общий prompt и дополнительно чистит типичный LaTeX-мусор из ответа, но source files лучше писать сразу в простом формате.
